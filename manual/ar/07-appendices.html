مرجع أوامر سطر الأوامر

كل أمر تقدّمه وحدة تحكم REA، كما يبلّغ عنه rea --llms للإصدار REA {{REA_VERSION}}، إضافةً إلى مجموعة mcp المخفية. وتُشغَّل الأوامر كـrea <command> ….

قراءة التوقيعات

الأقواس الزاوية تشير إلى الوسائط الموضعية. والأقواس المربّعة تشير إلى الاختيارية. للحصول على مخطط الوسائط الكامل لأي أمر، اكتب اسم الأمر في وحدة التحكم واضغط Schema؛ ولنص الاستخدام اضغط Help.

فهرس أدوات MCP

المجموعة الكاملة لأدوات REA المعروضة على الوكيل في هذا الإصدار. وكل مدخل هو اسم الأداة وعنوان عرضها وملخّص من سطر واحد.

المخططات في التطبيق

افتح REA → Tools لقراءة مخطط مدخلات JSON الكامل لأي أداة، أو لنسخ طلب وكيل جاهز، أو لإرساله مباشرة. وهذا الفهرس للتوجيه والطباعة.

وسائط سير العمل الموجّه

يصوغ REA طلب كل سير عمل موجّه من تعريفات وسائطه الخاصة. وهذه سير العمل الستة التي يحمّلها الشريط عند بدء التشغيل، مع كل وسيط وما إذا كان مطلوبًا.

{{WORKFLOWS}}

C.7 كيف يبني الشريط الطلب

  1. يستدعي الشريط rea guided-workflows --format json ويحتفظ بقائمة الوسائط لكل سير عمل.
  2. يجمع المعالج القيم ويطلب من REA صياغة الطلب (rea guided-workflow-prompt أو المصوغ المكافئ).
  3. إذا لم تتوفّر الصياغة، يعود التطبيق إلى طلب منظّم يحتوي وصف سير العمل وكائن JSON بالوسائط المقدَّمة.
  4. الطلب المراجَع في الخطوة 3 قابل للتعديل؛ وما في الصندوق هو ما يُرسَل.

المصطلحات

المصطلحالمعنى
Agent
الوكيل		عملية OpenCode للنموذج اللغوي التي تخطّط العمل وتستدعي الأدوات وتكتب الإجابة. يُختار لكل طلب من الشريط العلوي.
AgentEnv
بيئة الوكيل		حزمة بيئة محمولة لتطبيق ويب أو تطبيق سطح مكتب Linux، تُبنى من نسخة حيّة أو من التقاط، وتُستخدم للتحليل لاحقًا.
Artifact
الأثر		ملف مُصدَّر قيد التحليل: ملف تنفيذي، أو مكتبة، أو مثبّت، أو أرشيف، أو APK، أو Mach-O، أو صورة برنامج ثابت، أو التقاط، أو حزمة.
Bundle (evidence)
حزمة الأدلة		مستند JSON قانوني يحتوي سجلات الأدلة والبيانات الوصفية وتاريخ المجهولات. قابل للاستيراد والمقارنة بهوية السجل.
Cleanup pending
تنظيف معلّق		راية حالة في REA تعني أن محرّكًا ما زال يحتفظ بموارد يجب تحريرها قبل الخروج.
Evidence
الدليل		سجل دائم معنون بالمحتوى لحقيقة مرصودة، يُعرَّف بـev_ مع بصمة SHA-256 من 64 حرفًا.
Ghidraمحرّك التحليل الأصلي. ويتطلّب REA الإصدار 12.1.x.
Guidance
الإرشاد		كتب تشغيل REA المثبّتة. قابلة للبحث في تبويب Guidance وللقراءة بواسطة الوكيل.
Manifest
البيان الوصفي		جرد لمكوّنات أثر وعلاقاتها، يُستخدم للمقارنة وإعادة البناء.
MCPبروتوكول سياق النموذج (Model Context Protocol). واجهة stdio التي يستدعي الوكيل عبرها أدوات REA الـ255.
Occurrence
التواجد		ظهور محدّد لأثر أو مكوّن داخل جرد؛ يُستخدم لتركيز المقارنات دون تخويل الاستخراج.
Procedure
الإجراء		دالة أو طريقة في ثنائي أصلي أو مُدار، تُعرَّف بالاسم أو بالعنوان.
Provider
المزوّد		خلفية تحليل: Ghidra وIDA وHopper وCutter/Rizin وJEB وFrida وadb وPlaywright وغيرها. وتبلّغ مصفوفة القدرات عن التوفّر.
Reconstruction ledger
سجل إعادة البناء		قائمة حتمية مدعومة بالأدلة بالتزامات إعادة البناء، مع التغطية والمجهولات المتبقية.
Residual unknown
مجهول متبقٍّ		سؤال لا تجيب عنه الأدلة المتاحة. يُتتبَّع صراحةً حتى لا يُغلق بصمت.
Session
الجلسة		محادثة OpenCode منسوبة إلى مساحة عمل. تحتفظ بالرسائل ونشاط الأدوات وسجل الأدلة الحيّ.
Target
الهدف		أثر مفتوح حاليًا في محرّك تحليل، مع موارد محجوزة حتى إغلاقه.
Token limit / offset
حد الرموز / إزاحتها		عناصر تحكّم في إخراج النتائج الكبيرة: تحديد الحجم، أو التصفّح بتخطّي الرموز.
Workflow
سير العمل		قالب تحقيق متعدّد الخطوات يعرّفه REA، بوسائط مطلوبة واختيارية.
Workspace
مساحة العمل		المجلد الذي يعمل فيه الوكيل ونطاق سرد الجلسات ومربّعات الملفات.
